# Портфолио — Astro + Tailwind + GSAP

Одностраничное портфолио: тёмная навигационная тема, осенняя оранжевая
акцентная палитра, прелоадер, плавный скролл (Lenis) и scroll-анимации
(GSAP ScrollTrigger). Без React — всё на нативных Astro-компонентах
и лёгком ванильном JS/TS.

## Структура

```
src/
  components/    отдельные секции и переиспользуемые элементы (Icon, SideNav)
  data/
    content.js   ВЕСЬ контент сайта — имя, обо мне, навыки, проекты, соцсети
  layouts/
    Layout.astro шрифты, мета-теги, подключение Lenis
  scripts/
    animations.ts вся GSAP-логика (reveal, прогресс-бары, счётчики)
  styles/
    global.css   цветовые токены, шрифты, keyframes
public/
  images/        аватар и постеры проектов (сейчас — сгенерированные заглушки)
  favicon.svg
```

## Как наполнить своими данными

Практически всё редактируется в одном файле — **`src/data/content.js`**:

- `profile` — имя, роль, город, короткий текст под именем, путь к аватару и резюме
- `about` — абзацы «о себе» и цифры-достижения (стаж, кол-во проектов и т.д.)
- `achievements` — список наград/сертификатов/выступлений
- `skills` — навыки с процентом владения (влияет на длину прогресс-бара)
- `stack` — языки / фреймворки / инструменты (просто список строк)
- `projects` — карточки проектов: изображение 16:9, теги, ссылки на демо и репозиторий
- `socials` — ссылки на соцсети (иконки берутся из `Icon.astro` по ключу `icon`)
- `contact` — заголовок секции связи и email

### Изображения

- **Аватар**: `public/images/avatar.jpg` — квадратное изображение (сейчас показывается
  кругом через CSS `rounded-full`, поэтому важен центр кадра — лицо должно быть
  посередине квадрата).
- **Постеры проектов**: `public/images/projects/project-*.jpg`, соотношение **16:9**
  (например, 1280×720). Это правильный выбор формата — так же оформлены превью
  в Dribbble/Behance и в GitHub Social Preview, поэтому картинки будут смотреться
  единообразно и на самом сайте, и если решишь расшарить проект в соцсетях.
  Совет: используй скриншот интерфейса проекта с лёгким затемнением по краям —
  тогда акцентная рамка карточки не будет спорить с содержимым скриншота.
- Если хочешь избежать скриншотов интерфейса (например, для приватных проектов) —
  неплохая альтернатива: минималистичная обложка с названием проекта на фирменном
  фоне (как сейчас в заглушках) — тоже смотрится стильно и единообразно.

Просто замени файлы в `public/images/` на свои с теми же именами — пути менять
не нужно. Резюме — положи PDF в `public/resume.pdf`.

## Разработка

```bash
npm install
npm run dev       # http://localhost:4321
npm run build     # сборка в dist/
npm run preview   # локальный просмотр сборки
```

## Деплой на GitHub Pages

1. В `astro.config.mjs` замени:
   ```js
   site: 'https://ТВОЙ_НИК.github.io',
   base: '/НАЗВАНИЕ_РЕПОЗИТОРИЯ',
   ```
   Если сайт будет на `username.github.io` (репозиторий без под-пути) —
   `base` вообще нужно убрать (или оставить `'/'`).

2. Запушь проект в репозиторий на GitHub.

3. В настройках репозитория: **Settings → Pages → Source → GitHub Actions**.

4. Готовый workflow уже лежит в `.github/workflows/deploy.yml` — при каждом
   пуше в `main` сайт будет собираться и выкладываться автоматически.

## Что уже сделано по анимациям

- **Прелоадер** — инициалы + полоса загрузки, исчезает перед появлением героя
- **Hero** — дрейфующий градиентный «аврора»-фон, редкие плавающие частицы,
  плавное появление текста после прелоадера
- **Скролл-reveal** — все секции проявляются снизу при попадании во вьюпорт
- **Прогресс-бары навыков** и **счётчики цифр** — анимируются при скролле к ним
- **Магнитная кнопка** в блоке «Связь» — слегка тянется за курсором
- Всё уважает `prefers-reduced-motion` — анимации отключаются, если у
  пользователя включена системная настройка уменьшения движения
